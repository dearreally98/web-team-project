# web-team-project

# 가상 미술관 웹사이트

## 1. 프로젝트 소개 및 선정 이유

이 프로젝트는 HTML5와 CSS3를 활용하여 가상의 미술관 웹사이트를 제작한 팀 프로젝트입니다.

다양한 시대의 미술 작품을 소개하고, 사용자가 원하는 작품 정보를 쉽게 확인할 수 있도록 구성하였습니다. 또한 Git과 GitHub를 활용하여 브랜치를 생성하고 병합하는 협업 과정을 경험하기 위해 본 주제를 선정하였습니다.

## 3. 주요 기능

### 고정 네비게이션 메뉴

- 화면을 스크롤해도 상단에 고정
- 클릭 시 해당 섹션으로 이동

### 미술관 소개

- 설립연도
- 보유 작품 수
- 전시관 수

### 시대별 타임라인

- 중세미술
- 근대미술
- 현대미술

각 시대를 클릭하면 해당 전시 섹션으로 이동할 수 있습니다.

### 작품 갤러리

- 시대별 작품 분류
- 카드 형태 레이아웃 구성
- 대표 작품 클릭 시 상세 페이지 이동

### 작품 상세 페이지

- 작품 이미지
- 작품명
- 작가
- 제작연도
- 작품 설명

### 관람 안내

- 운영 시간
- 관람 요금
- 위치 안내
- 관람 유의사항

## 6. 브랜치 전략

`main` 브랜치는 최종 결과물을 관리하는 브랜치입니다.

각 팀원은 기능별 브랜치를 생성하여 작업한 뒤, GitHub를 통해 병합(Merge)을 진행하였습니다.

### 브랜치 목록

```bash
feature/header-nav
feature/banner-intro
feature/timeline
feature/gallery
feature/visitor-info
feature/footer
feature/detail-page
```
